# Tally 2.0

## Updating from the earlier version
1. In the current Tally, save a backup: Settings → Backup → Save a backup file → Save to Files.
2. In your GitHub repository, open the `tally-web` folder, click **Add file → Upload files**, drag in
   `index.html`, `cloud.js`, `sw.js` and `manifest.webmanifest`, and click **Commit changes**.
3. Wait a minute or two, then open Tally on your phone while online. Your entries convert automatically;
   the old data is kept as a copy inside the app.
4. Turn on sync: Settings → Sync → enter your email and a password → **Create account**.
5. On your laptop, open the same address and **Sign in** with that email and password.

## Good to know
- Sync uses your own Firebase project on the free Spark plan. No card is on file, so it can't charge you.
- Tally works offline; changes sync when you're back online.
- Settings → Backup still saves a file you can restore from, and Export spending as CSV opens in Excel.
